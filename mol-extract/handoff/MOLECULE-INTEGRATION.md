## ⚠ 한 번에 성공하기 — 반드시 지킬 것 (실패 방지 가드레일)

우리가 이 히어로를 만들며 실제로 겪은 함정이다. 그대로 지키면 재작업 없이 끝난다.

1. **레퍼런스가 정답이다.** 새로 상상하지 말고 `Union Hero 3D.dc.html`을 브라우저로 먼저 열어 동작을 본 뒤, 그 수치·좌표·애니메이션을 1:1로 옮겨라. `this._P`(노드 데이터·좌표·문구)는 통째로 복사.
2. **히트스팟·라벨·하이라이트는 U 이미지와 같은 플로트 컨테이너(`#ufloat`) 안에 넣어라.** 바깥 고정 레이어에 두면 U가 부유할 때 어긋난다(우리가 겪은 최다 버그).
3. **좌표계 통일.** 노드는 이미지 자연크기(1269×1239) 기준 %로 저장하고, 스테이지 픽셀로 변환해 배치. Canvas 없음 — 순수 `<img>` + 절대배치.
4. **0×0에서 초기화 금지.** 컨테이너 크기가 잡힌 뒤(useEffect + ResizeObserver) 좌표를 계산. 안 그러면 "스크롤해야 나옴"·좌상단 뭉침 발생.
5. **SSR 끄기.** `dynamic(() => import('@/components/MolecularHero'), { ssr:false })`. `window`/`document`는 mount 이후에만.
6. **노드 진입(zoom) 시 상단 GNB/헤더를 숨겨라**(opacity 0 + pointer-events none), 복귀 시 복원. 내부 분자가 메뉴와 겹친다.
7. **내부 분자 중심 y를 화면 중앙 아래쪽**(약 56%)에 두고 방사 반경이 헤더/하단을 넘지 않게. 상단 치우침 금지.
8. **잘림 방지.** 확장 구조는 스테이지·뷰포트 안에 들어오는지 1440/1600/1920px에서 확인. 넘치면 반경·중심만 조정.
9. **기존 히어로 절대 보존.** 좌측 카피·역할탭·CTA·헤더·배경. 우측 시각 영역만 교체.
10. **한 번에 다 쓰지 말 것.** 아래 순서로, 단계마다 스크린샷을 레퍼런스와 대조하고 다음 단계로.

**구현 순서(체크리스트):**
- [ ] ① 기존 히어로 스냅샷 확보 + 컴포넌트 교체 지점 확인
- [ ] ② U 이미지 + 7 히트스팟 정적 배치(플로트 컨테이너 안, 좌표 정확)
- [ ] ③ idle 모션(flU/uSway 부유 + 마우스 틸트) + 바닥 리플
- [ ] ④ hover 돋보기 렌즈 + 라벨 강조/디밍
- [ ] ⑤ click 줌인(포탈 버스트 + uSuck) + 헤더 숨김
- [ ] ⑥ 내부 분자(코어 + 방사 기능원자 + 가지1 + 배경입자) + 궁금증 잠금 티저
- [ ] ⑦ 상세 패널(도입효과 체크리스트) + 도입문의/소개서 인라인 폼(모달 금지)
- [ ] ⑧ ← / ESC / 배경클릭 줌아웃(uUnsuck) + 헤더 복원
- [ ] ⑨ 반응형(≤1024 스택, ≤640 목록형) + 접근성(button/aria/ESC/reduced-motion)
- [ ] ⑩ 성능(rAF 없음이라 가벼움) + cleanup(ResizeObserver/listener 해제)

각 단계 완료 시: 변경 파일 · 결과 스크린샷 · 기존 히어로 보존 여부를 보고하고 다음 단계로.

## 🚑 화면에 아무것도 안 뜰 때 (blank) — 이 순서로 진단

1. **`.next` 캐시 삭제 후 재시작.** 서버 HTML에 옛 클래스명이 남아있으면 확정 캐시 문제: dev 서버 종료 → `rmdir /s /q .next`(win) / `rm -rf .next` → `npx next dev`.
2. **컨테이너는 서버 렌더, 내부만 클라이언트.** 고정 크기(`position:relative; height:clamp(...)`) `hero-molecular-area` div는 HeroSection에 그대로 두고, 그 안에서만 `dynamic(() => import('@/components/MolecularU'), { ssr:false, loading: () => <div style={{position:'absolute',inset:0}}/> })`. 컨테이너가 SSR에 안 나오면 조건부 렌더/문법오류로 우측 열 자체가 드롭된 것 → 그 조건 제거.
3. **Error Boundary로 감싸라.** `ssr:false` 컴포넌트가 마운트 중 throw하면 화면이 조용히 빈다. 경계로 감싸 에러를 표면화.
4. **진짜 원인은 브라우저 F12 콘솔.** `curl`로 SSR HTML을 grep하지 말 것(클라이언트 에러는 거기 없음). 콘솔 첫 빨간 에러를 확인 — 흔한 원인: 삭제된 state의 잔존 참조(`setFormMode` 등), mount 전 `ref.current` null 접근, `getContainedRect`가 크기 0에서 호출됨.
5. **크기 0 가드.** `containerRef` 크기가 0이면 좌표 계산/렌더를 건너뛰고 ResizeObserver로 >0 될 때 재계산. 초기 1프레임 blank가 고착되지 않게.
6. 포트 확인(3000/3004 등 실제 실행 포트)과 하드 리프레시(Ctrl+Shift+R)로 서비스워커/캐시 배제.

## 📱 모바일 대응 (배포 전 필수 — 안 하면 잘림)

데스크톱은 고정 px 좌표(내부 분자 cx/cy/rad)라 좁은 화면에서 잘린다. 아래를 반드시 구현.

- **idle 히트스팋은 이미 반응형**(`imgRect` 기준) — 유지.
- **내부(zoom) 분자 좌표를 상대값으로**: `cx = W*0.62, cy = H*0.56, rad = Math.min(W,H)*0.34`, 코어/비드 크기도 `rad` 비례. (W,H = 컨테이너 실측) → 데스크톱 동작 유지하며 자동 축소.
- **`≤768px` 폴백(권장)**:
  - 히어로 좌우 → 세로 스택. U는 상단에 `object-fit:contain`으로 축소(절대 잘리지 않게), 높이 ~320px.
  - 노드 클릭 → 화면 꽉 채우는 방사 분자 대신 **하단 시트(bottom sheet)** 로 상세(업무영역·벤더·설명·도입효과 체크리스트·기능 리스트·소개서/문의 폼). 작은 화면 방사 분자는 가독성 없음.
  - 히트스팟/버튼 탭 타깃 ≥44×44px, 라벨 목록형.
  - `prefers-reduced-motion`: 부유·리플·스태거 정지, 정보·기능은 유지.
- **검증 뷰포트**: 360×640, 390×844, 768, 1024, 1440, 1920 전부에서 U·라벨·내부 분자가 안 잘리는지 확인.

## ▶ Claude Code에 붙여넣을 프롬프트

> 우리 사이트(`Union_frontend`, Next.js 14 App Router)의 히어로 우측 3D 분자 시각화를 아래 스펙대로 구현/교체해줘. `handoff/Union Hero 3D.dc.html`이 **완성 레퍼런스**이고, 동작·수치·애니메이션을 그대로 재현하면 된다. 좌측 카피·역할탭·CTA·헤더 등 기존 히어로 요소는 절대 건드리지 말 것.
>
> **0. 통합 지점**
> - 히어로 분자는 `@/components/MolecularHero` (`src/components/MolecularHero.tsx`)에서 `dynamic(() => import(...), { ssr:false })`로 마운트된다. 이 컴포넌트를 새 구현으로 교체한다.
> - 이미지 `union-u-v2.png`를 `public/images/`에 넣고 `/images/union-u-v2.png`로 참조.
> - 데이터는 `src/components/molecular-data.ts`로 분리(아래 구조). 정보 문구는 이미 채워져 있으니 그대로 사용하되 팀이 수정 가능하게.
>
> **1. 기술**
> - React + 순수 DOM/CSS(3D 라이브러리 불필요). U는 `<img>` 1장 + 절대배치 오버레이. 상태는 `useState`(idle / zoomed solutionId / form mode).
> - 인라인 style 또는 CSS module. 브랜드 토큰: accent `#F5333F`, ink `#111214`, ink2 `#6B655C`, line `#E7E2D8`, bg `#FBFAF7`.
>
> **2. Idle**
> - U 이미지가 `@keyframes flU`(translateY -24px + rotate ±1.2°, 6s) + `uSway`(translate, 11s)로 부유. 마우스 이동 시 컨테이너 기준 3D 틸트(rotateY ≤6°, rotateX ≤5°).
> - U 위 7개 빨간 구슬 위치(이미지 % 좌표)에 히트스팟. 각 히트스팟: 부드러운 레드 그라데이션 하이라이트(`hsPulse` 밝기 일렁, 노드별 위상차) + 바깥쪽 글래스 라벨(업무영역명 크게 / 벤더 작게). 히트스팟·라벨은 U와 **같은 플로트 컨테이너 안**에 넣어 함께 움직여야 함(어긋남 방지).
> - 하단에 물결 리플: 동심 타원 4겹(`uRip` 6s, 스태거) + 소프트 블러 그림자 + 안쪽 레드 링.
>
> **3. Hover(히트스팟)**
> - 그 지점이 돋보기 렌즈로 확대(같은 U 이미지를 background로 zoom 2.4배, 원형 클립). 선택 라벨 강조, 나머지 라벨 opacity↓.
>
> **4. Click = "빨려들어가는" 줌인**
> - 클릭 노드에서 빛 포탈 버스트(흰빛+레드 코어 원 + 확산 링 + 8방향 광선).
> - U 이미지가 그 노드를 transform-origin으로 `uSuck`(scale 1→7, 끝에서 opacity 0 + blur 9px, 0.9s)으로 빨려들어가며 사라짐.
> - 좌측 카피가 상세 패널로 전환(← 돌아가기 / eyebrow SOLUTION·벤더 / 업무영역명 / 벤더 / 설명 / **도입 효과 체크리스트 3** / CTA).
> - 우측에 해당 솔루션 내부 분자 조립: 중심 글라스 코어(업무영역명+벤더+"기능 N·도입효과 M") → 사방 방사형으로 기능 원자 5개가 코어에서 싹터 나옴(`budIn`/스태거), 각 기능에서 **가지 하나**(하위 원자 1개)만 분열, 은은한 배경 입자망으로 여백 채움. 기능 원자 hover 시 도입효과 문구 표시. 기능 원자·글씨는 큼직하게(비드 ~92px, 이름 ~21px).
> - ← / ESC / 배경클릭 시 `uUnsuck`(역재생)으로 U 복귀.
>
> **5. CTA / 리드 폼**
> - 상세 패널의 `도입 문의하기`·`상세 소개서 받기` 클릭 시 인라인 폼 확장. 폼: "소개서에 담긴 내용/문의 시 제공" 체크리스트(모드별) + 이름·회사·이메일·연락처(+문의는 메시지) + 개인정보 동의 체크박스 + 신청 버튼 → 제출 시 완료 메시지. **모달·팝업 금지**(인라인).
>
> **6. 데이터 구조** (`molecular-data.ts`)
> ```ts
> export interface Feature { n: string; e: string } // 기능명, 도입효과 한 줄
> export interface Solution {
>   id: string; area: string; vendor: string;
>   x: number; y: number; r: number;   // U 이미지 위 빨간 구슬 %좌표 + 자연px 반지름
>   desc: string; gain: string[];       // 설명 + 도입효과 3
>   feats: Feature[];                   // 4~5개
> }
> ```
> 7개 노드 좌표(이미지 1269×1239 기준): Microsoft(17.3,9.3,r30)·엔코아(83.0,9.9,r32)·AhnLab(16.8,43.1,r37)·Adobe(83.6,43.1,r37)·이스트소프트(23.2,71.0,r34)·Autodesk(77.0,71.0,r34)·닥터소프트(50.0,85.0,r33). 내용은 레퍼런스 DC의 `this._P`에서 그대로 가져올 것.
>
> **7. 반응형/접근성**
> - ≤1024px: 좌우 세로 스택, U 축소, 라벨은 아래로. ≤640px: 히트스팟을 목록형 버튼으로, 클릭 시 상세는 하단 시트. 히트스팟·기능 원자는 `<button>`(aria-label). ESC 닫힘. `prefers-reduced-motion`이면 부유·리플·스태거 정지, 정보는 유지.
>
> **8. 검수**
> - 3초 안에 7개 업무영역 읽힘 / 라벨·하이라이트가 U 부유에 맞춰 따라감 / 클릭 줌인·줌아웃 자연스러움 / 좌측 기존 히어로 보존 / 브랜드 레드 단일 액센트.
>
> 구현 전 레퍼런스 DC를 브라우저로 열어 동작을 확인하고, 각 단계(정적 배치→idle모션→hover렌즈→click줌인→내부분자→폼→반응형) 완료마다 스크린샷으로 대조할 것. 한 번에 다 쓰지 말고 단계별로.
